### 🛠️ What I work on

- ⚙️ **Systems & performance**: modern C++ (C++20), Rust, concurrency, benchmarking
- 🧠 **ML in production**: model serving, ONNX Runtime, dynamic batching, CI/CD and deployment around models
- 🌐 **Full-stack products**: Django / DRF backends, React + TypeScript frontends, Docker, LLM-powered features
- 🧩 **Fundamentals**: data structures, algorithms (CSES, Codeforces, Advent of Code), OS internals (OSTEP)

### 🚀 Featured projects

| Project | What it is | Stack |
|---|---|---|
| [**finton**](https://github.com/ELyoussfiHamza/finton) | A dynamic-batching inference server for ordinary CPUs, inspired by NVIDIA Triton. Built to measure what batching really buys you on a CPU. | C++20 · ONNX Runtime · CMake |
| [**pixcii**](https://github.com/Elyoussf/pixcii) | A media-to-ASCII converter: images, real-time video playback and URL support, auto-fit to the terminal. | C++ |
